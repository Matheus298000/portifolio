### Opção 2: Pelo Site do GitHub (Passo a Passo Manual)
1. Acesse sua conta no GitHub: [github.com](https://github.com)
2. Clique no botão verde **"New"** (ou acesse `https://github.com/new`).
3. Dê o nome do repositório:
   - **Recomendado**: `Matheus298000.github.io` *(com este nome, seu site terá o link direto: `https://Matheus298000.github.io/`)*
   - Ou se preferir outro nome: `portfolio` *(o link será: `https://Matheus298000.github.io/portfolio/`)*
4. Deixe o repositório como **Público** e **NÃO** marque a opção de adicionar README (já temos um).
5. Clique em **"Create repository"**.
6. No seu computador, abra o PowerShell nesta pasta e execute:
   ```bash
   git remote add origin https://github.com/Matheus298000/SEU-REPOSITORIO.git
   git push -u origin main
   ```
7. No GitHub, entre em **Settings** > **Pages**:
   - Em **Branch**, selecione `main` e a pasta `/ (root)`.
   - Clique em **Save**.
8. Pronto! Em 1 minuto seu site estará online para o mundo todo ver.
